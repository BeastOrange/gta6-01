Solmar Bay is an original open-world crime game set in a fictional sun-soaked coastal city: explore on foot and by car, steal cars, outrun the SBPD police as your wanted stars rise, and run four story jobs for Mara Voss while traffic and pedestrians fill the streets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is plain static files under `game/`.
